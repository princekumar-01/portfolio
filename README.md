# Portfolio

Personal portfolio site of **Prince Kumar** — Computer Science student.

A single-file, framework-free site (`index.html`) with an editorial, paper-like design:
warm off-white background, near-black ink and a rust accent. No build step, no
dependencies, no tracking.

## Features

- Light and dark theme (toggle persists your choice)
- Fully responsive, keyboard accessible
- Projects, skills, experience and contact sections
- Résumé available as a direct download (embedded, so nothing breaks if files move)
- Prints cleanly to a single-page PDF

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy

The site is static, so any static host works. To publish with GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**.
